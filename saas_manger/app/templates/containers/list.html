The manager found no Docker socket at {{ docker_socket }}, so it cannot start or stop containers. To enable this page, give the saas-manager-web service the daemon socket:

  • volumes: → - /var/run/docker.sock:/var/run/docker.sock
  • group_add: → - "0", so the non-root panel user may open it
  • environment: → - DOCKER_SOCKET=/var/run/docker.sock

Be aware of what this grants: the Docker socket is root-equivalent on this host, so anything that can talk to it can control every container. This panel only ever calls start / stop / restart on the services you list in APP_SERVICES, and it refuses the protected ones below outright — but the socket itself is the real boundary, so only mount it on a host you control.
