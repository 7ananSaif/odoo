Apps are managed here

Odoo's own Apps screen is hidden inside every tenant database by saas_tenant_guard: a tenant does not install its own software. The provider does — from here.

What a tenant is allowed to run comes from its plan ("bouquet"). Installing an app the plan does not include is refused, and every install, removal or upgrade is written to the audit log.

The catalogue is not a fixed list: opening a tenant registers every application its Odoo reports, and Rescan apps makes Odoo re-read its addons paths first — so a module folder added on the server is installable without editing any code. {% if discovered_count %}
